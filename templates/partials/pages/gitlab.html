GitLab pipeline

Importer les resultats CI/CD et afficher le dashboard du projet ici.

Flow reel

Le pipeline lance Robot Framework, garde output.xml et les screenshots comme artifacts, puis l'app peut les importer pour remplir Dashboard, Analyse et Historique.

1 Garder le pipeline actuel

Pas besoin de changer toute la CI. Il faut surtout conserver output.xml et les screenshots comme artifacts.

2 Importer les artifacts

Mode manuel: telecharger le dossier artifacts puis le deposer dans Analyse. Mode auto: ajouter un endpoint Flask qui lit GitLab API.

3 Piloter le projet ici

Dashboard, Analyse, Historique, statuts Corrige/Bloque et screenshots restent centralises dans cet outil.

robot_tests:
  stage: test
  script:
    - robot --output output.xml tests/
  artifacts:
    when: always
    paths:
- output.xml
- log.html
- report.html
- screenshots/
    expire_in: 7 days
